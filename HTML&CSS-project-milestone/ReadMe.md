# Simple Blog Website

This project is a basic blog website created using only HTML and CSS. The purpose of this project is to demonstrate a simple static website layout that could serve as a starting point for a personal blog, a portfolio, or any other content-focused website.

## Features

- **Responsive Design**: The layout adjusts to various screen sizes, making the blog mobile-friendly.
- **Header and Footer**: Standard header with navigation links and footer with contact/social media links.
- **Article Sections**: Each article contains a title, date, content, and author information.
- **Styled Buttons and Links**: Links and buttons are styled consistently across the site.
- **Navigation Bar**: A simple navigation bar for easy access to different sections of the blog.

## Technologies Used

- **HTML5**: Markup language for creating the structure of the website.
- **CSS3**: Stylesheet language used for styling and layout.
  
No JavaScript frameworks, libraries, or additional backend technologies are used.
